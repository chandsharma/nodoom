NO DOOM

Privacy policy

No Doom does not collect, store, sell or share personal data.

Effective date: 17 November 2026

Data collection and sharing

No Doom requests no Internet permission and contains no analytics, advertising, telemetry, crash reporter, account system or cloud service. It cannot send app data to the developer or a third party.

Accessibility service

No Doom uses Android Accessibility to identify full-screen Reel screens in the official Instagram app and intercept vertical gestures that would advance to another Reel. It can process Instagram’s live on-screen structure and foreground app changes.

When another app is in front, No Doom immediately removes its transparent gesture layer. It uses the foreground package name only for that safety transition and does not request or traverse that app’s window. Android System UI is recognised only so the notification shade and Quick Settings always receive their own gestures.

Accessibility content is processed in memory on the device. No Doom does not save usernames, captions, messages, images, videos, controls or accessibility-tree content, and does not perform social actions on the user’s behalf.

Data stored on the device

No Doom stores only protection state and deadlines, optional notification and feedback choices, setup/disclosure acknowledgement, Instagram recognition timestamps and version, and a service-interruption timestamp. Clearing app data removes these values. Android backup and device-transfer backup are disabled.

User control

No Doom never prevents the user from disabling Accessibility or uninstalling the app. Its payment-compatibility control can turn off its own Accessibility service after confirmation; Android requires the user to re-enable that service manually.

Instagram

No Doom is independent of Instagram and Meta. It does not use Instagram or Meta APIs, read Instagram files, cookies or tokens, or ask for an Instagram password. The official Instagram app continues to handle all account and network activity.

Contact and source

Questions can be opened publicly in the No Doom issue tracker. The complete source code is available at github.com/chandsharma/nodoom.
