# Security policy

No Doom handles Accessibility data, so security and privacy reports deserve care.

Do not open a public issue containing private Instagram content, diagnostic dumps, account details, signing material or an exploitable bypass. Contact the repository owner privately through the security-reporting option on GitHub. Include the affected version, Android version and minimal reproduction steps with personal data removed.

Official APKs are published only in GitHub Releases. Release checksums and the signing-certificate SHA-256 fingerprint are recorded in the release notes. The signing key is never stored in Git or GitHub Actions.

Supported versions will be listed after the first production release. Alpha builds receive best-effort security fixes and must not be treated as a complete control.
